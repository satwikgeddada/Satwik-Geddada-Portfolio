# Satwik Geddada | Portfolio

Personal portfolio of **Satwik Geddada**, an AI & Full-Stack developer. It showcases projects, skills, education, experience and achievements in a single-page, animated, responsive site.

**🔗 Live site:** https://satwik-geddada-portfolio.vercel.app/

## ✨ Sections

- **Home:** intro, current focus and a resume download
- **About:** background and interests
- **Skills:** programming, frontend, backend and databases, AI/ML, tools
- **Projects:** featured work with source and live-demo links
- **Education and Experience:** timeline view
- **Achievements:** hackathon wins, leadership and certifications
- **Contact:** email, social links and resume

## 🛠️ Tech stack

- [Next.js](https://nextjs.org) (App Router) with TypeScript
- Tailwind CSS (via PostCSS)
- Framer Motion for animations
- [Geist](https://vercel.com/font) font via `next/font`
- ESLint for linting
- Deployed on Vercel

## 🚀 Run locally

```bash
git clone https://github.com/satwikgeddada/Satwik-Geddada-Portfolio.git
cd Satwik-Geddada-Portfolio
npm install
npm run dev
```

Open http://localhost:3000.

Other scripts:

```bash
npm run build   # production build
npm run start   # serve the production build
npm run lint    # run ESLint
```

## 📂 Structure

```
├── public/    # images, resume.pdf and other static assets
├── src/       # pages, components and app code
├── next.config.ts
├── eslint.config.mjs
└── postcss.config.mjs
```

## ✏️ Customizing

To reuse this as your own portfolio, replace the content in `src/` (projects, experience, achievements), swap the images and `resume.pdf` in `public/`, and update the metadata (title, description, Open Graph tags).
